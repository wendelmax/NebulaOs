# NebulaOS — Programa de Certificação

## Público-Alvo

Engenheiros de infraestrutura, DevOps, consultores e integradores.

## Níveis de Certificação

### NEB-101: NebulaOS Foundations

| Item | Detalhe |
|---|---|
| **Duração** | 8h (autoestudo + laboratório) |
| **Exame** | 40 questões, 70% de acerto, 60 min |
| **Preço** | R$ 300 |
| **Validade** | Não expira |
| **Conteúdo** | Arquitetura, instalação CLI, criação de tenant, gerenciamento de usuários |

### NEB-201: NebulaOS Administrator

| Item | Detalhe |
|---|---|
| **Pré-requisito** | NEB-101 |
| **Duração** | 16h (laboratórios práticos) |
| **Exame** | 50 questões + laboratório prático (2h), 75% de acerto |
| **Preço** | R$ 600 |
| **Validade** | 2 anos |
| **Conteúdo** | Multi-tenancy, provedores (BareMetal, K8s), billing, backup, monitoração |

### NEB-301: NebulaOS Advanced Deployer

| Item | Detalhe |
|---|---|
| **Pré-requisito** | NEB-201 |
| **Duração** | 24h (laboratórios avançados) |
| **Exame** | Projeto prático (8h) + defesa oral (1h) |
| **Preço** | R$ 1.200 |
| **Validade** | 2 anos |
| **Conteúdo** | HA, DR, Bare metal provisioning, GSLB, performance tuning, security hardening |

### NEB-401: NebulaOS Compliance & Government

| Item | Detalhe |
|---|---|
| **Pré-requisito** | NEB-201 |
| **Duração** | 8h |
| **Exame** | 40 questões, 80% de acerto |
| **Preço** | R$ 800 |
| **Validade** | 2 anos |
| **Conteúdo** | LGPD, ISO 27001, gov.br, eMAG, SISP, documentação para licitação |
