## Matriz de Prioridades

| Prioridade | Definição | Exemplos |
|---|---|---|
| **P1 — Crítica** | Sistema indisponível ou perda de dados | API fora do ar, perda de recursos |
| **P2 — Alta** | Funcionalidade principal degradada | Login lento, provisionamento falhando |
| **P3 — Média** | Funcionalidade secundária com problema | Relatório de billing incorreto |
| **P4 — Baixa** | Dúvida, melhoria, cosmetico | Sugestão de feature, typo na UI |

## Exclusões de SLA

- Problemas causados por infraestrutura do cliente (não gerenciada por nós)
- Versões não oficiais ou modificadas do NebulaOS
- Desastres naturais, guerra, greve (force majeure)
- Manutenções programadas (comunicadas com 48h de antecedência)

## Manutenções Programadas

- Janela: 2h mensais, comunicadas com 48h de antecedência
- Atualizações críticas de segurança: comunicadas com 24h
- Sem janela fixa — agendadas conforme melhor horário para o cliente
