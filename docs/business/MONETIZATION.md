# NebulaOS — Modelo de Monetização

## Premissas

- Core 100% open source (Apache 2.0) — sem funcionalidades bloqueadas
- Receita via serviços complementares, não por retenção de funcionalidade
- Público-alvo: governo e instituições que já não podem comprar nuvem proprietária

## Modelo Proposto: Open Core + Serviços

### 1. Suporte Corporativo (assinatura anual)

| Tier | Público | Inclui | Preço sugerido |
|---|---|---|---|
| **Community** | Qualquer um | GitHub Issues, Docs, Discord | Gratuito |
| **Standard** | PMEs / Autônomos | Suporte email 8x5, SLA 48h, atualizações estáveis | R$ 12.000/ano |
| **Enterprise** | Governo / Instituições | Suporte 24/7, SLA 4h, onboarding presencial, treinamento, certificação | R$ 60.000-120.000/ano |
| **Sovereign** | Ministérios / Forças Armadas | Suporte dedicado, implantação on-prem, compliance LGPD/ISO 27001, acordo de nível de serviço personalizado | Sob consulta |

### 2. Serviços Profissionais

| Serviço | Descrição | Preço |
|---|---|---|
| Implantação assistida | Setup do NebulaOS + provedores + integração com identidade existente | R$ 30.000-80.000 |
| Treinamento de operadores | Curso de 3 dias para equipe de infraestrutura | R$ 15.000 (até 10 pessoas) |
| Certificação individual | Prova para administrador NebulaOS certificado | R$ 800/pessoa |
| Consultoria de migração | Migração de workloads de nuvens públicas para NebulaOS | R$ 200/hora |
| Desenvolvimento de blueprint | Criação de blueprint personalizado para o cliente | R$ 15.000-40.000 |

### 3. Marketplace (comissão)

- Provedores de infraestrutura pagam 10-20% de comissão sobre blueprints vendidos
- Blueprints verificados ("Nebula Verified") têm prioridade no catálogo
- Parceiros de tecnologia pagam para ter integração certificada

### 4. SaaS Gerenciado (NebulaOS Cloud)

- Versão hosted para quem não quer gerenciar a própria infraestrutura
- Precificação por recursos gerenciados (R$/core/mês)
- Opção soberana: dados residentes em datacenter brasileiro
